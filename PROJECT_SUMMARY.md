# Project Summary

## Resume Bullet

Built a provider-tolerant multi-agent RAG research assistant using Gemini API, ChromaDB, document ingestion, retrieval, structured planning, and citation-aware report synthesis, with a deterministic local fallback for reliable demos without external API availability.

## What It Demonstrates

- Agent-style orchestration with planner, knowledge, retrieval, and writer stages.
- Local RAG over ChromaDB with document ingestion from PDF, text, or UTF-8 files.
- Provider abstraction for Gemini plus graceful fallback when keys, quota, or permissions fail.
- Evaluation script for latency, success rate, and citation coverage.
- Portfolio-friendly sample document and sample output.

## Suggested CV Bullets

- Developed a multi-agent RAG research assistant with planner, retriever, and writer agents.
- Integrated ChromaDB for local semantic retrieval and Gemini API for report generation.
- Implemented graceful provider fallback, citation-aware synthesis, and evaluation scripts for repeatable demos.
