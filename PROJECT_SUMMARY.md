# Project Summary

## Resume Bullet

Built a provider-tolerant research-agent RAG assistant with live web search, local ChromaDB retrieval, Gemini/Hugging Face/Ollama provider switching, document ingestion, chat commands, and citation-aware report synthesis.

## What It Demonstrates

- Agent-style orchestration with planner, web search, knowledge, local RAG retrieval, and writer stages.
- Live web search through DuckDuckGo HTML search with source markers.
- Local RAG over ChromaDB with document ingestion from PDF, text, or UTF-8 files.
- Runtime provider/model selection for Gemini, Hugging Face, Ollama, and auto mode.
- Graceful fallback controls when keys, quota, or permissions fail.
- Windows launchers for one-shot queries, chat mode, and ingestion.
- Expanded sample document corpus for local RAG demos.
- Evaluation script for latency, success rate, and citation coverage.
- Portfolio-friendly sample documents and sample output.

## Suggested CV Bullets

- Developed a research-agent RAG assistant combining web search, local ChromaDB retrieval, and LLM synthesis.
- Implemented runtime model/provider switching across Gemini, Hugging Face, Ollama, and auto fallback modes.
- Built document ingestion, citation-aware report generation, chat commands, and evaluation scripts for repeatable demos.
